# Формула выпуска ТОМ-ТУР

> **шок-факт в первом кадре → «Отматываем время!» → портал → 9–11 эпох (одна эпоха = один «вау-факт» = 4–6 с) → сегодня («и все стоят на том самом камне») → кнопка-вопрос в камеру.**

## Карта по секундам (эталон 001 — Нью-Йорк, 60 с)

| с | бит | что в кадре |
|---|---|---|
| 0,0–2,4 | **Хук**: «Над Таймс-сквер — лёд! Почти высотой с Эмпайр-Стейт!» | Таймс-сквер, сверху наползает ледяная стена; текст-хук огромными буквами; Том в шоке |
| 3,8–6,0 | «Не веришь? Отматываем время!» | хитрый прищур, крутит часы |
| 6,0–6,7 | **портал из часов** | туннель времени, годы летят назад |
| 6,7–56 | 10 эпох по 4–6 с | каждая: табличка года + шкала, свой мир, свой костюм, свой переход, 1 факт-панчлайн |
| 56–60 | **кнопка**: «Куда махнём дальше? Пиши город — отмотаем!» | Том в камеру, часы светятся, «ПОДПИШИСЬ» за 1 с до конца |

## Меню вариаций (чтобы не было конвейера — каждый выпуск берёт другое)

- **Хук:** невозможная картинка («море над Кремлём») · шок-цифра («6 млн скелетов под ногами») · вопрос-загадка («почему Пиза падает уже 800 лет?») · «вы ошибались» («Эйфелеву башню хотели снести») · обратный отсчёт («у этого города было 3 имени»).
- **Структура:** хронология геология → сегодня · обратная (сегодня → вглубь) · один предмет сквозь века · «3 тайны города» · спор двух эпох · «что стояло на этом месте».
- **Финал перед кнопкой:** петля к хуку · неожиданный вывод · личная реплика Тома · вопрос зрителю по теме. Кнопка-бренд «Пиши город — отмотаем!» остаётся, фраза перед ней — новая.
- **Понятность:** термины только простыми словами; каждый факт привязан к знакомому объекту; повороты «но…», «а потом…».

## Правила

- **Первый кадр** = самый невероятный факт выпуска, показанный картинкой (лёд над Таймс-сквер). Текст-хук 2–3 слова, вопрос с «?!».
- **Хронология назад → вперёд:** хук в «сегодня», провал в самое глубокое прошлое (геология), потом вперёд к сегодняшнему дню. Петля: финал снова в «сегодня».
- **Одна эпоха — один факт**, реплика ≤ 14 слов, удар в конце (цифра, сарказм, неожиданность).
- **Каждые 3–4 факта — шутка** (сухая, взрослая): «Позеленела — от нью-йоркских цен», «Двадцать один слон — стоит!».
- **Эмоция Тома меняется на ключевом слове** каждой реплики.
- **Переходы не повторяются** внутри выпуска (каталог — `docs/style.md`).
- **Звук с 0,0 с**, каждый переход — свой SFX, у эпохи своя атмосфера.
- **Финал — вопрос** к зрителю про следующий город.

## Чек перед рендером

- [ ] хук-факт виден в первом кадре без звука, текст-хук = первая реплика;
- [ ] все факты с источником в `docs/sources/<эп>.md`;
- [ ] ударения U+0301 во всех словах `lines.json`, шёпота нет;
- [ ] у каждой эпохи: табличка года, костюм, эмоции по словам, свой переход;
- [ ] субтитры не на лице Тома;
- [ ] длина 50–60 с, громкость mean ≈ −20 дБ, пик ≤ −1 дБ;
- [ ] «ПОДПИШИСЬ» в последнюю секунду.

## Что сработало (001)

- Хук «лёд над Таймс-сквер» — визуально невозможное, но правда.
- Провал «в подвал» к камню возрастом 450 млн лет (Том в каске шахтёра стучит по сланцу).
- Сарказм на знакомых фактах (статуя, «купили» за гульдены).
- Костюм на каждую эпоху — владелец: «можно в каждом ролике выглядеть по-новому».

## Что сработало (002 — Москва)

- Хук-картинка «невозможное, но правда» второй раз подряд работает: море над Красной площадью.
- Петля: финал возвращается к хуку («все ходят по дну древнего моря»), на экране призрак моря над толпой.
- Связка эпох одним предметом (белый камень = дно моря → белокаменный Кремль → окаменелость в блоке).
- Шутки-надписи в кадре: «КУПАНИЕ ЗАПРЕЩЕНО», «ключи: 0 шт.», «тук.» по Царь-колоколу, «снова Нью-Йорк!».
- Переодевание «пуф» на ключевом слове внутри одной сцены.

## Чего не делать

- **Вода** (002): реплики-связки без факта («тут плескалось тёплое море», «потом пришёл ледник», «сегодня тут…»). Каждая реплика = цифра/имя/деталь + панчлайн.

- «Листание страниц» и ластик как переходы — владелец забраковал.
- Шёпот — неслышно.
- Детская подача, мультяшная милота.
- 12 fps движения — дёргано (12 fps только у «кипения» линии).
