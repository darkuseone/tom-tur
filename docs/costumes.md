# Гардероб Тома (переиспользовать!)

Все костюмы — ключи `OUTFIT` в `engine/tom.js` (шапка — `HAT6`/`hat5`, обувь — `BOOTS`, реквизит — `PROPS`). Правило (владелец, 19.10.2026): **если готовый костюм реально подходит эпохе нового города — берём его**, новый рисуем только когда старого нет или он не по смыслу. Перекраска (свой `top/topD/topL`, `print`) — дешёвый способ сделать вариант: новая запись в `OUTFIT` с тем же `detail`/`hat`.
