## Запас (проверено, не вошло)
- Хьюз — Новороссийское общество (зарегистрировано в Лондоне), рабочие из Уэльса.
- Сталино → Донецк 1961 (при десталинизации).
- Ковалевский назвал бассейн «Донецким» в 1827.

## Не берём
- MH17 отдельной сценой (тяжело и спорно для площадок) — только в общей цифре погибших.
- Текущая линия фронта и процент контроля (данные меняются, свежих подтверждённых нет) — карта 2022 без линии фронта, только «объявлено» и «не признано ООН».
- Голодомор в Донбассе — нет компактной проверенной цифры по региону.
- Донецко-Криворожская республика 1918 — спорная трактовка, не нужна.

## Спорное и как сформулировано
- Калка: место — «вероятно р. Кальчик»; голосом не называем, только «половцы/степь».
- Уголь 1721 (Капустин) — приоритет оспаривается → голосом «империя нашла уголь» без имени.
- 1991: Луганская 83,86 % — в одном источнике 73 % (Yahoo, выброс) → «восемьдесят четыре процента» (Донецкая 83,9; ≈ 84 % у обеих по MSU).
- 2014: «с помощью России» — по решению ЕСПЧ 2025 (эффективный контроль); 14 000 — нижняя граница УВКПЧ (14 200).
- Статус: «для ООН — Украина» — резолюции ГА ES-11/4 (2022) и 68/262 (2014, Крым); формулировка ООН — «временно оккупированные территории».
