## Спорное и как сформулировано
- Число каторжников 736–775 → «почти восемьсот».
- Сааринен и «корзина отказов» — легенда, записей жюри нет → «по легенде».
- Кратность 13–14 → «в четырнадцать раз» (102 / 7 ≈ 14,6).
- Лотерея собрала «чуть больше $100 млн» → «почти все деньги».
