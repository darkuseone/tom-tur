# Ударения и произношение (словарь проекта)

Владелец 22.10.2026: «на слух некоторые слова звучат неправильно». Проверка 004: ручные ударения совпали с моделью RUAccent везде, кроме двух имён → ошибки в основном от того, что ElevenLabs **иногда игнорирует U+0301** (особенно на редких словах, именах, числительных).

## Порядок (до платной озвучки)
1. Ставить U+0301 во всех словах из 2+ слогов (ё — без знака).
2. `python3 tools/stress.py <эп>` — сверка с моделью RUAccent (словарь + омографы по контексту) и с таблицей ниже. Расхождения решать глазами: имена собственные модель часто не знает (тогда верить источнику/словарю).
3. Слова из таблицы с пометкой «IPA» писать в `lines.json` транскрипцией в косых чертах `/…/` с `ˈ` перед ударным слогом — так `eleven_v4` читает произношение напрямую (документация ElevenLabs, «IPA with Eleven v4»). Результат проверять на слух у важных слов.
4. Если владелец услышал ошибку — строка сюда (слово, как прозвучало, как писать), перегенерировать только эту реплику (`tts.py lines <эп> <ключ>`).

## Словарь (стресс-проверка читает 1-й и 2-й столбцы)
| слово | как писать в lines.json | как ошибался ElevenLabs / заметка |
|---|---|---|
| тэджо | Тэджо́ | корейское имя; модель RUAccent ставит «Тэ́джо» — неверно для русского произношения (ударение на последний слог) |
| седжон | Седжо́н | имя короля |
| коджон | Коджо́н | имя короля |
| гангнам | Гангна́м | район Сеула; RUAccent даёт «Га́нгнам» |
| сеул | Сеу́л | |
| потом | пото́м | RUAccent путает с «по́том» (пот) — ставить вручную (011) |
