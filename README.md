# ТОМ-ТУР

Рисованные Shorts/Reels/TikTok: кот **Том** отматывает время города — от камня под ним до сегодняшнего дня, за минуту.

- Стиль: цветной карандаш и акварель на бумаге, 2.5D-камера, физические переходы, Spider-Verse-провалы.
- Рендер: HTML-canvas + GSAP → [HyperFrames](https://github.com/heygen-com/hyperframes) → MP4 1080×1920.
- Голос: ElevenLabs (eleven_v4), липсинк: Rhubarb Lip Sync.

```bash
tools/setup.sh                       # зависимости
tools/render.sh 001-new-york         # пересобрать выпуск 001
```

Документы: `CLAUDE.md` (правила и пайплайн), `docs/passport.md` (паспорт канала), `docs/character.md` (Том), `docs/style.md`, `docs/sound.md`, `docs/pipeline.md`, `docs/episode-formula.md`, `docs/cities.md`, `docs/decisions.md`.
