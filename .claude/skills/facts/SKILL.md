# /facts <эп> <город> — факты → сценарий → lines.json

Правила — `CLAUDE.md` §6, формула — `docs/episode-formula.md`. Читать только их и `docs/cities.md`.

1. **Тип хука и структура** — сверить с `docs/cities.md` (колонки «хук», «структура», строка «Следующему выпуску»): не повторять прошлый выпуск. Меню — `docs/episode-formula.md` «Меню вариаций».
2. **Поиск**: WebSearch `mode: standard`, по 5 запросов в одном ответе (параллельно). Запросы на английском + на языке страны (корейский, японский…): они находят местные факты. Конкретную цифру проверять WebFetch по одной статье с вопросом «какие точно даты/числа/названия». Нужна 1 энциклопедия/музей + 1 СМИ/научпоп.
3. **Обязательные темы**: войны, оккупации, революции, катастрофы города — отдельной эпохой и прямыми словами («оккупация Японии, 35 лет», «город четыре раза переходил из рук в руки и лежал в руинах»): кто, когда, цифра потерь/разрушений, без натурализма. Мифы и ассоциации зрителя («Сеул = soul», «Samsung из Сеула») — проверить; опровержение мифа = хук или поворот. Тон — взрослый: сухой сарказм, а не «детские» гэги.
4. **Отбор**: 9–11 эпох, хук-факт для первого кадра. Брать факт, если в нём есть цифра, имя, поворот («но…», «а потом…»), связь с знакомым (Россия, Москва, YouTube, K-pop). Если источники расходятся — формулировать по меньшей цифре или словом «почти». Неподтверждённое — в раздел «Не берём» (в 004: «рыба сварилась в пруду», «первым выпил кофе»).
5. `docs/sources/<эп>.md`: таблица `| реплика | факт | источник |` + «Запас (проверено, не вошло)» + «Не берём».
6. **Реплики** `episodes/<эп>/lines.json`: ключи h1 h2 s1…sN t1 x1; тег эмоции в начале (`[shocked, loud]`, `[sly]`, `[deadpan]`, `[laughing]`, `[proud]`; шёпот — нельзя); U+0301 после ударной гласной в каждом слове из 2+ слогов, «ё» без ударения; ≤ 14 слов; шутка каждые 3–4 реплики. h1 начинается с шок-слова, h2 = «Отматываем время!» (≤ 1,2 с), x1 = «Куда махнём дальше? Пиши город — отмотаем!».
7. **Ударения**: `python3 tools/stress.py <эп>` → разобрать все замечания; трудные слова — по словарю `docs/stress.md` (имена, IPA `/…/` для слов, которые ElevenLabs уже читал неверно).
8. **Длина до озвучки**: `python3 tools/est.py <эп>` → цель 50–58 с. Реальная речь выходит на ~6 % длиннее оценки (004: 57 → 60,6 с), поэтому целиться в est ≤ 55 с. Эпоха ≈ 45–55 букв ≈ 4,5–5 с. Резать сначала слабую эпоху целиком, потом связки.
9. `episode.json` (scenes, worlds, title, hook) и `script.md` (таблица: эпоха | мир | костюм | реплика | переход | SFX). Отправить script.md владельцу (SendUserFile) + 3 строки. Ждать «ок», если владелец не сказал «делай сразу».
