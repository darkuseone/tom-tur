# /sound <эп>

Правила — `CLAUDE.md` §5, `docs/sound.md`. Делать после того, как миры готовы (времена событий — от картинки).

1. `node tools/evdump.cjs <эп>` → `episodes/<эп>/ev.json` (все `EV.*`). Список ключей: `python3 -c "import json;print(list(json.load(open('episodes/<эп>/ev.json'))['EV']))"`.
2. Нужные звуки искать в `assets/sfx/CATALOG.md` (`grep -i`). Проверить, что файлы есть: `for f in a b c; do [ -f assets/sfx/$f.mp3 ] || echo НЕТ $f; done`.
3. Недостающие — `python3 tools/tts.py sfx assets/sfx/<имя>.mp3 <сек> "<англ. промпт, без музыки>" [loop]`, **не больше 5 параллельно** (`( cmd & cmd & wait )`). Лупы атмосфер 6–10 с, музыка — `tts.py music assets/sfx/music_<город>.mp3 20 "<инструменты страны + лёгкий бит, без вокала, loopable>"` (mix сам зациклит). Тихие файлы — не беда: mix выравнивает каждый клип по RMS.
4. `python3 tools/sfxcheck.py assets/sfx/<новые>.mp3` → все `ok` (HARSH — EQ или заменить). Каждый новый — строкой в CATALOG.md в свой раздел (с пометкой выпуска).
5. `episodes/<эп>/sound.py` — по образцу прошлого выпуска: `sfx = [('файл', время, дБ), …]` (время — `e('ключ', сдвиг)`, `S0['сцена']`, `LS('s3')`), `beds = [('луп', начало, конец), …]`, `music = 'music_<город>'`. На каждый переход — свой звук за 0,1–0,3 с до S0; на каждое ключевое слово — событие; под каждой эпохой — атмосфера.
6. **Ворота:** `python3 tools/soundcheck.py <эп>` → «ok» (атмосфера под каждой сценой, звук на каждый переход и каждое событие `EV.*`, ≥ 3 SFX на сцену, все файлы на месте, музыка задана).
7. Микс делает `tools/render.sh` (мастер −14 LUFS, true peak ≤ −1 dBTP). Поправить только звук после рендера — `tools/render.sh <эп> remix` (картинка из готового `build/<эп>/video.mp4`).

## Саунд-дизайн как в хорошем мультфильме (владелец, 03.11.2026)
- **Три слоя всегда:** атмосфера эпохи (луп) + музыка выпуска (под характер города, приглушать в тяжёлых эпохах `music_duck`) + точечные SFX.
- **Переход = свой звук**, «влетающий» за 0,1–0,3 с до S0 (свист, удар, шорох бумаги, пар, вспышка) и приземление в новой эпохе (удар, щелчок, гул).
- **Каждое слово-событие озвучено:** штамп, удар молота, лай, щелчок рубильника, «тук» счётчика, фанфара награды, звонок навигатора; HUD-плашки и счётчики — короткий «тук»/«поп».
- **Действия Тома:** часы («щёлк» + перемотка), переодевание («пуф»), удар/озноб/смех — звуком.
- **Петля:** последний звук кнопки = первый звук хука.
- Новые звуки — короткие (1,5–3 с), промпт на английском «…, no music»; лупы атмосфер 8 с с `loop`.

- **Фоли Тома и света** (11.11.2026): каждое физическое действие Тома с предметом и каждое изменение света (вспышка, щелчок лампы, гром) — свой звук; ответ предмета (упал, звякнул, скрипнул) — второй звук через 0,1–0,3 с.
