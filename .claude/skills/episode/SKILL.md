# /episode <NNN-slug> <Тема> — выпуск ТОМ-ТУР от и до

**Ничего готового не переделывать без просьбы владельца** — выпуски, уже сданные или выложенные, не трогать.
**Одна сессия = один выпуск.** Выпуск ≈ 600 тыс. токенов контекста; второй выпуск в том же чате приведёт к сжатию контекста и экономии на рисовании (так проседали 011–018). Если владелец просит несколько тем — это `/week`.
Субагентов для сцен не запускать (CLAUDE.md §7а): всё делает эта сессия по очереди, но **не экономит на рисовании и звуке**.

**Режим.** Если в запросе есть «бриф недели» / «делай сразу» / «координатор» — сценарий не ждёт «ок», делаешь до готового ролика; в конце отчитываешься координатору (`send_message`). Иначе — сценарий владельцу и ждать «ок».

## 0. Старт (≈ 5 мин)
Читать только: `CLAUDE.md`, `STATUS.md`, `docs/episode-formula.md`, `docs/cities.md`, последний раздел «Выводы» в `docs/stats.md`, `docs/api.md`. **Не читать** движок, `tom.js`, миры прошлых выпусков — только `grep -n` и диапазоны; готовые детали — `docs/library.md`.
`bash tools/setup.sh > /dev/null` (ffmpeg, Rhubarb, npm, RUAccent). Ветка `episode-<NNN>-<slug>` от свежего main (или та, что задана сессии). `python3 tools/new_episode.py <NNN-slug> "<Город>"` — каркас из последнего выпуска: `PROGRESS`, `QUESTION`, хук на всю h1, 30 fps уже включены.

## 1. Факты и сценарий — скил `facts`
- 20–30 кандидатов, каждый факт — 2+ источника → `docs/sources/<эп>.md` (таблица + «Запас» + «Не берём» + «Спорное и как сформулировано»).
- Обязательно: войны/оккупации/катастрофы города — прямо, цифрами (без натурализма); миф, который зритель «и так знает» — проверить и обыграть; безопасность площадок (CLAUDE.md §6).
- Сценарий по §6а и `docs/script-research.md` (хук без ответа, «но/поэтому», поворот на 40–50 %, число-сувенир, критик ≥ 8,5): хук-вопрос (шок-слово первым, тезис ≤ 3 с), 7–9 узнаваемых эпох по 5–7 с, явный ответ в последней трети (`EV.answer` для плашки), почему перешлют, петля кадром и звуком. Хук/структура/палитра — не как в 3 последних строках `docs/cities.md` (или по брифу недели).
- `lines.json` с тегами и U+0301 → `python3 tools/stress.py <эп>` (разобрать все замечания) → `python3 tools/est.py <эп>` ≤ 55 с. Сначала резать слабую эпоху, потом связки.

## 2. Озвучка и таймлайн
`python3 tools/tts.py lines <эп>` → `python3 tools/prep_voice.py <эп>` → `python3 tools/build_data.py <эп>` (печатает границы сцен). В `scenes.js`: `HOOK_LINES` (≤ 3 слов в строке), `YR`, `YEARS`, `QUESTION { q, a, at: () => EV.answer }`; `episode.json → worlds` по мере готовности сцен.

## 3. Костюмы — скил `costume`
Сначала каталог `docs/costumes.md`; новые — одним файлом через `tools/add_costume.py`, проверка `tools/tomsheet.cjs` (один Read). Худи города — перекраска `hoodie` (`print`, `capTxt`).

## 4. Миры — скил `scene`, по одной сцене, каждая целиком одним Write
Общие детали города — `episodes/<эп>/<город>.js` сразу после `props.js` (гора, архитектура, люди эпохи, транспорт).
**Планка каждой сцены = эталон** (`assets/ref/etalon_001_002.jpg`): кадр до краёв, своё цветное освещение, ≥ 5 планов + передний план `lay(<1)` + атмосфера, ≥ 8 живых фигур, ≥ 12 предметов быта, земля с фактурой, архитектура с деталями. Минимум ≈ 9–15 КБ кода на сцену. На каждое ключевое слово — действие в кадре + смена эмоции + событие `EV.*` (для звука). Переход — свой, физический, не из `docs/style.md`.
После каждой сцены: `tools/check.sh <эп> <3–4 времени сцены>` → один Read листа; ≤ 2 кругов правок; ≤ 450 мс/кадр.

## 5. Ворота качества картинки — в коде, до звука и рендера (без скриншотов ради сравнения)
1. `python3 tools/detail.py <эп>` — все сцены «ok» (≥ 5 планов, передний план, атмосфера, ≥ 9 КБ); подсказку «фигур мало» — закрыть кодом (добавить людей/толпу), а не скриншотами.
2. Детальность закладывать при написании сцены по чек-листу планки (раздел 4), а не догонять потом: проверочные кадры — только `tools/check.sh` по 3–4 времени на сцену, как обычно.
3. `tools/vs_etalon.py` — **не обязателен**, только если владелец попросит сравнение с эталоном.
4. Обложка `w_cover.js` → `node tools/cover.cjs <эп>` → Read `build/<эп>/cover_small.jpg`.

## 6. Саунд-дизайн — скил `sound`
`node tools/evdump.cjs <эп>` → `sound.py`: атмосфера-луп под каждой сценой, звук на каждый переход (−0,5…+0,2 с от S0), звук на каждое событие `EV.*`, ≥ 3 SFX на сцену, музыка выпуска (новая 20 с — под характер города), `music_duck` под тяжёлые эпохи. Звуки сначала из `assets/sfx/CATALOG.md`; новые — `tools/tts.py sfx` (≤ 5 параллельно) → `tools/sfxcheck.py` → строка в CATALOG.
**Ворота:** `python3 tools/soundcheck.py <эп>` → «ok».

## 7. Рендер и сдача — скил `deliver`
`tools/render.sh <эп>` фоном (30 fps, ≈ 7 мин на 56 с) → `tools/finalcheck.sh <эп>` (50–70 с, −14 LUFS, TP ≤ −1, chat < 29,5 МиБ) + Read `fin/sheet.jpg` и `fin/loop.jpg`. Правка только звука — `tools/render.sh <эп> remix` (без перерендера картинки).
Тексты `publish.md`, документы (`docs/cities.md`, `docs/style.md` — переходы, `docs/costumes.md`, `docs/episode-formula.md` — что впервые, `assets/sfx/CATALOG.md`, `STATUS.md` — готово + слабые места), `python3 tools/libindex.py`.
Чат: SendUserFile `build/<эп>/chat.mp4` + `cover.png`, 2–3 строки (что нового, кредиты, честные слабые места), тексты выкладки колонкой. Git: коммит, push, PR в main (+ `subscribe_pr_activity`). Режим недели — ещё `send_message` координатору: «ГОТОВО <NNN> | PR #… | длина … | LUFS … | слабые места: …».

## Экономия лимита подписки (владелец, 03.11.2026) — качество не трогать
Режем только «холостые» токены, не рисование и не звук:
- Читать только файлы из шага 0, остальное — `grep -n` / `sed -n` диапазоном. Не перечитывать файлы, которые уже писал сам.
- Поиск фактов: ≤ 8–10 WebSearch (пачками по 4–5 параллельно), WebFetch — только чтобы уточнить цифру.
- Сцену писать одним Write; проверка — один `tools/check.sh` на 3–4 времени, Read одного листа; правки — точечными python-replace, не переписывать файл.
- Длинные выводы обрезать (`| tail`); рендер — фоном, не опрашивать (придёт уведомление).
- Не делать ничего сверх задачи: никаких перерендеров, сравнений с эталоном и «улучшений» готового.

## Ловушки, которые уже стоили времени (019)
- Слой земли в ближнем `lay` перекрывает дальние объекты, стоящие ниже горизонта → землю рисовать в том же или более дальнем слое, чем объекты на ней.
- Светлые силуэты на снегу не видны → тёмные силуэты + цветной контровой свет.
- Плашки/цензура/HUD не должны закрывать лицо Тома (Том x ≈ 300, голова y ≈ 1000–1150).
- `hatch` по огромным площадям (стены тоннеля) → 600+ мс/кадр; `gap` 12–14 на больших формах.
- Переход длиннее 0,3 с после S0 съедает первое ключевое слово сцены — ключевое событие не раньше S0 + 0,35 с.
- Кнопка: финальная секунда — тот же ракурс и звук, что первый кадр хука (петля).
