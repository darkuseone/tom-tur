# /episode <город> — выпуск ТОМ-ТУР

Один агент, по очереди (CLAUDE.md §7а). Читать: `CLAUDE.md`, `STATUS.md`, `docs/episode-formula.md`, `docs/cities.md`, `docs/api.md`. **Не читать** движок, tom.js и миры прошлых выпусков — только `grep -n` и диапазоны. Ветка: `git checkout -b episode-<NNN>-<город>` от свежего main.

| шаг | что | как |
|---|---|---|
| 0 | каркас | `python3 tools/new_episode.py <NNN-город> "<Город>"` (props.js с общими хелперами, direct.js, transitions.js — из прошлого выпуска) |
| 1 | факты, сценарий, реплики | скил **facts**: источники → `script.md` в чат → `lines.json` → `tools/est.py` (est ≤ 55 с) |
| 2 | озвучка и таймлайн | `python3 tools/tts.py lines <эп>` → `python3 tools/prep_voice.py <эп>` → `python3 tools/build_data.py <эп>` (печатает границы сцен) |
| 3 | HUD | `scenes.js`: `HOOK_LINES` (≤ 3 слов), `YR` (год + подпись каждой сцене), `YEARS`; годы туннеля в `props.js` (`const yrs`), костюм туннеля `DIR.tunnel.outfit` |
| 4 | костюмы | скил **costume**: сначала каталог, новые — `tools/add_costume.py`, проверка `tools/tomsheet.cjs` |
| 5 | общие детали города | `episodes/<эп>/<город>.js` (архитектура, флора, символы — один файл, в worlds сразу после props.js) |
| 6 | сцены | скил **scene** на каждую: хук → … → today → button (button и туннель — по образцу прошлого выпуска) |
| 7 | контроль | `python3 tools/detail.py <эп>` — все сцены «ok» (≥ 5 планов, атмосфера, передний план), затем `tools/check.sh <эп> <середины сцен>` — контакт-лист рядом с `assets/ref/etalon_001_002.jpg` (эталон 001 Нью-Йорк + 002 Москва); беднее — дорисовать до звука |
| 8 | звук | скил **sound** |
| 9 | сдача | скил **deliver**: обложка, рендер фоном, `tools/finalcheck.sh`, тексты, документы, чат, коммит, PR |

Хук под удержание: движение и звук с 0,0 с, первое слово — шок-слово, «Отматываем время!» ≤ 1,2 с, кнопка ≤ 2 с с петлёй в хук; длина 50–70 с (цель 50–58).
Каждый выпуск отличается (тип хука, структура, переходы, палитра, костюмы, финальная фраза) — сверять с `docs/cities.md`.
