# /fix <эпизод> <правки>

1. Разобрать правки по пунктам; постоянное правило → `docs/decisions.md` (с датой) и `CLAUDE.md`.
2. Голос/текст: правка `lines.json` → `tools/tts.py lines <эп> <ключ>` (только изменённые) → `tools/prep_voice.py <эп> <ключ>` → `tools/build_data.py <эп>`.
3. Картинка: правка мира/рига/режиссуры → `tools/render.sh <эп> snap <время>` до и после, смотреть кроп в полном размере.
4. Звук: `sound.py` / `tools/mix.py <эп>`; громкость mean ≈ −20 дБ, пик ≤ −1 дБ.
5. Полный рендер `tools/render.sh <эп>` (фоном) → SendUserFile `build/<эп>/chat.mp4` + список, что исправлено. Коммит + пуш.
6. Если изменились факты/хук — обновить `episodes/<эп>/publish.md` (названия, описания, хэштеги).
