# /scene <эп> <сцена> — мир сцены

API — `docs/api.md` (не читать движок), готовые детали — `docs/library.md` (`grep -n`, копировать функцию). Общие хелперы уже в `props.js`: `human()` (люди с руками/лицом/шапками), `wtk(ключ, 'слово')`, `puffK`, `neon`, `cityBlock`, `crowd`, `poster`, `candle`, `flick`, `lerpC`.

1. `python3 tools/new_scene.py <эп> <сцена> <ключ-реплики> <костюм> ["ГОД" "ПОДПИСЬ"]` — каркас w_<сцена>.js (EV по словам, KEYW, 3 плана, DIR, TRANS_IN) + запись в episode.json. YR/YEARS в scenes.js — вручную (скрипт подскажет).
2. Мир писать **одним Write целиком**, но **богато** (CLAUDE.md §4 «Детальность задников», владелец 27.10.2026): ≥ 5 планов (`lay` 30 → небо с облаками/птицами, 14–20 → дальний силуэт, 6–10 → архитектура эпохи с деталями, 3–5 → главный объект и люди, 1 → земля с фактурой и Том, 0.6–0.8 → передний край по бокам), ≥ 8 живых фигур `human()` + животные/транспорт, ≥ 12 мелких предметов быта, атмосфера (дымка, `motes`, `rays`, `glow`, дым из труб). Дома — с наличниками, вывесками, трубами, черепицей, а не голые прямоугольники; земля — с фактурой, без пустот. Кадр заполнен до краёв (камера ближе, объекты крупные и уходят за край), своё цветное освещение сцены. Эталон — 001 Нью-Йорк и 002 Москва: `assets/ref/etalon_001_002.jpg`.
3. События — только от слов: `EV.x = wtk('s3', 'слово')`; на каждом ключевом слове — действие в кадре + смена эмоции (`act`) + звук (потом в sound.py).
4. Переход — свой, физический, не из `docs/style.md`. Удобно: `if (k < 0.5) drawBuf(A) else drawBuf(B)` + оверлей в `scr()`; маска-окно — `inCircle`/`inPath`.
5. Проверка: `python3 tools/detail.py <эп>` — все сцены «ok» (иначе дорисовать), затем `tools/check.sh <эп> t1 t2 …` (середина сцены, ключевые слова, переход S0±0,2) → один Read `build/<эп>/shots/sheet.jpg`. Не больше 2 кругов правок, правки — точечным python-replace, не переписывать файл.

## Композиция (кадр 1080×1920)
- **Безопасные зоны** (`SAFE`, CLAUDE.md §4): текст/HUD/важное — y 280–1600, x 70–900; выше 280 и ниже 1600 — только фон. Табличка года y ≈ 290–460, шкала ≈ 488, «ТОМ-ТУР» ≈ 540, хук ≈ 470, субтитры ≈ 1480: голова Тома — вне 1430–1530. HUD сцены (бирки, календари, `note()`) — y 600–1420, x ≤ 900. Красные линии на контакт-листе — проверить каждый кадр.
- Том `x` 300–420 и `s` ≈1.0–1.1, если в сцене есть главный объект (центр/право свободны). Палец/взгляд — на объект.
- Передний план (lay < 1) только по краям кадра (x < −200 или > 1250) — не закрывать Тома.
- Камера `[t, x, y, z]`: z 0 — без зума, 0.1–0.2 — ближе, < 0 — шире; `'x'` — провал Spider-Verse. Большой y → видим ниже.

## Ловушки (проверено на 004)
- Эмоции — только 14 из api.md (`sly` нет → молча не работает).
- `KEYW` — слово ровно как в субтитре, с пунктуацией (`'дней.'`, `'«столица».'`); `wtk` пунктуацию сам игнорирует.
- `ctx.globalAlpha` не делает `human()` прозрачным (wash ставит свою альфу) → призраки/силуэты через `sil(pts, col, a)`.
- `ctx.fill('evenodd')` с rect+arc дыру не вырезает → заливка экрана + `inCircle(..., () => drawBuf(...))`.
- Смена костюма внутри сцены: в `pose` вернуть `outfit: t > EV.x ? 'b' : 'a'` + `puffK(...)` в lay(1).
- Предмет в лапе: `afterCat: (t,u,P) => { x = P.x + P.hand[0]*P.s; y = P.y + P.hand[1]*P.s; ... }`.
- Отражение в воде: `ctx.save(); ctx.translate(0, 2*Y); ctx.scale(1,-1); …; ctx.restore()`.
- Символы: флаги рисовать правильно (тхэгык ≠ японский флаг), советский значок `soviet` — не в чужих странах (есть `suitK`).
- Петля «финал = место хука»: из хука отдать набор функций (`window.SQ = {...}` с флагом «всё горит») и переиспользовать в today.
- Табличка года «крутит цифры» на переходах (8822 → 8361) — это норма движка.
- Нелатинский/некириллический текст (хангыль, иероглифы): шрифты `KHand`/`KSign` (хангыль). Для нового письма — ttf с Google Fonts (`curl -A "curl/7" "https://fonts.googleapis.com/css2?family=..."` даёт ttf) → `assets/fonts` + @font-face и `document.fonts.load` в `engine/page.html`.
- Скорость: ≤ 450 мс/кадр; `hatch`/`crayon` по большим площадям и тысячи `ell` — дорого (крапинки рисовать `ctx.fillRect`).

## Ловушки (проверено на 019)
- Земля в ближнем `lay` перекрывает дальние объекты, стоящие ниже горизонта (лагерь исчез под вырубкой) → землю рисовать в том же или более дальнем слое.
- Светлые силуэты на снегу не читаются → тёмный силуэт + цветной контровой свет.
- Плашки, цензура, HUD-карточки не закрывают лицо Тома; HUD сцены — ниже 680 (на 612 висит плашка-вопрос `qchip`).
- `hatch` по огромным площадям → 600+ мс/кадр: `gap` 12–14 на больших формах.
- Переход длиннее 0,3 с после S0 съедает первое ключевое слово сцены.
- Окно с видом внутри комнаты: `ctx.save(); ctx.beginPath(); ctx.rect(...); ctx.clip(); push(x, y, k); вид(t); pop(); ctx.restore()` — проверить, что вид закрывает окно целиком по высоте.
- Петля: хук отдаёт свои планы через `window.<КЛЮЧ> = {...}`, кнопка их переиспользует; последний ключ камеры кнопки = первый ключ камеры хука.

## Свет, глубина, взаимодействие Тома (владелец, 11.11.2026 — обязательно в каждой сцене)
- **Свет по рецепту** (`docs/api.md` «Свет»): выбрать ОДИН главный источник (окно, лампа, костёр, закатное солнце, неон, экран) и построить от него всё: `lightPool` под ним, `shaft`/`rays` от него, `castShadow` от Тома, людей и крупных предметов в сторону ОТ источника, `moodDark` — углы и даль темнее и холоднее, блики/`glow` на металле, стекле, воде; `DIR.light = { side, rim }` — контровой свет Тома в цвет источника. Второй источник — контрастного цвета (тёплый + холодный). `BLOOM = 0.3` в scenes.js уже включён. Свет меняется на ключевом слове (вспыхнул, погас, молния, рассвет) — это событие и звук.
- **Глубина**: 6–8 планов с разным z (40 небо → 20 даль → 10 → 6 → 3 → 1 Том → 0.6 передний край), между планами `depthFog` (дальние светлее и холоднее, ближние темнее и насыщеннее), передний план — тёмные силуэты по краям (рама кадра), камера всегда чуть движется (параллакс), частицы на двух глубинах (мелкие далеко, крупные и размытые близко).
- **Том взаимодействует** — в каждой сцене ≥ 1 физическое действие с предметом мира на ключевом слове: берёт, тянет рычаг, стучит, сдувает пыль, открывает, роняет, уворачивается, греет лапы, светит фонарём, садится на объект. Средства: `prop` + `propAng`, `hand`/`handF` к координатам объекта, `afterCat` (предмет в лапе), `squash`/`tilt` на удар, а объект отвечает (качнулся, загорелся, упал, отскочил) + звук-фоли. Том не «стоит рядом и показывает», а участвует.
- Проверка в коде: `tools/detail.py` требует свет и взаимодействие в каждой сцене.

## Ловушки и приёмы (проверено на 024 — эталон света и глубины)
- **Плоская стена = нет света.** Большая заливка (стена, пол) без градиента выглядит «картоном»: поверх — `lighter`-градиент от источника + `moodDark` от него же; пол темнее и теплее стены, на нём `lightPool` и длинные `castShadow`.
- **Коридор / перспектива из колец**: слой заливать только «кольцом» между дальней и ближней аркой (`shape([...внешняя, ...внутренняя.reverse()])`), иначе ближний слой закрывает дальние. Пример — `segs()` в `episodes/024-pekin/w_bunker.js`.
- **Окно в стене**: стену рисовать кусками вокруг проёма (4 прямоугольника или `moonGate()` из `pekin.js` для круглого) — тогда небо и город за окном лежат в своих `lay()` и дают параллакс.
- **Падение героя с камерой** (двор → подземелье): плоскость героя непрозрачна ниже земли; экранная координата слоя `y_экр = Y + (960 − CAM.y) / z` — по ней ставить передний план для нижнего положения камеры. Пример — `w_dig.js`.
- **Люди за главным объектом не видны**: средний план с фигурами поднимать выше верха главного объекта или уводить вбок; проверять на листе, что фигуры читаются (в 024 уступы пещеры пришлось поднять на 230 px).
- `neon()` по умолчанию рисует шрифтом `KSign` (без кириллицы) и центрируется в (x, y) — для русского текста `{ font: 'Osw' }`.
- Иероглифы — `hz()`/`hzV()` (шрифт `CHand`, `pekin.js`); вывески и свитки сразу дают «антураж».
- `detail.py` считает фигуры по вызовам `human(` — обёртки (`wk`, `P`, `mar`) он не видит, это только подсказка. Сцена, собранная из планов хука (`today`), всё равно должна нести ≥ 9 КБ своего рисунка: свой стенд, тележка, люди.
- Смена света на слове — это три правки сразу: цвет/альфа источника, `screenFill(..., 'lighter')` на кадр и `DIR.light.rim`; плюс звук (`neon_off`, `switch_clunk`, `bulbs_chain_on`).
- Порядок работы, который уложился в одну сессию: общий файл города (палитра, крыши, фонарь, предмет-герой, переход) → хук (отдаёт планы через `window.BQ`) → сцены по одной с одним `check.sh` (6–8 времён, включая S0 ± 0,2) → правки одним python-replace.
