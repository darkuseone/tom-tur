# Библиотека звуков ТОМ-ТУР (переиспользовать!)

Правило (владелец, 19.10.2026): **сначала ищу здесь**, новый звук в ElevenLabs генерирую, только если подходящего нет. Новый звук → сюда строкой (имя, длина, что). Похожее по смыслу берём даже «с натяжкой»: вода, удары, свист, шорох, атмосферы — универсальны.
