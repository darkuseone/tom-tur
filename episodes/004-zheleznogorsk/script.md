# 004 — Железногорск: сценарий (черновик v1, на «ок» владельцу)

Оценка длины (`tools/est.py`): **≈54,6 с**. Голос — Дмитрий (eleven_v4).
**Хук:** «Плутоний для атомных бомб — внутри этой горы!» (тип — **рентген-разрез / тайна**: гора раскрывается, внутри реактор).
**Структура:** **«рассекреченное досье»** — хронология 1950 → сегодня, каждая эпоха открывается штампом «РАССЕКРЕЧЕНО» с номером пункта (1/9…9/9). Не было ни в 001–003. Глубокой геологии нет — по просьбе владельца время отдано комбинату и лагерю.
**Петля:** хук «гора-тайна» → финал «город, которого не было на картах, — в твоём навигаторе».
**Тон:** лагерь (s3–s5) — без шуток, Том серьёзен. Сарказм — в «секретности» и Енисее.

## Эмоции по словам
шок (Плутоний) → прищур (Отматываем) → суровый (Сталин) → хитрый (бомбы) → мрачный (Первыми, пятьдесят один) → серьёзный (Восемьдесят тысяч, грызть) → шок (Сталин/семнадцать тысяч) → сарказм (нет на картах), «пустой взгляд» (Ага, железные) → гордость (реактор) → сухой сарказм (сливают) → блаженство у батареи (батареи), гордость (Первым) → невозмутимость (десятого) → шок (России) → гордость (ГЛОНАСС), самодовольный (навигаторе) → игриво в камеру.
