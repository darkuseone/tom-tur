# 014 — Лос-Анджелес: сценарий (v1) · ТЕСТ правил §6а

- **Хук-вопрос:** «Надпись „Голливуд“ сделали не для кино. А для чего?» (самый узнаваемый объект города, «вы ошибались»).
- **Ответ на хук:** s6 + a1 — реклама участков «Голливудленд», 1923, ставили на полтора года; «ленд» сняли в 1949 (≈ 36–45 с, последняя треть).
- **Структура:** хронология, «один холм сквозь века» — гора Ли с будущей надписью виден в каждой эпохе (асфальтовые ямы, деревня, вышки, студия, акведук…), надпись появляется только в ответе.
- **Почему перешлют:** «скинь тому, кто мечтает о Голливуде» + сарказм: «временная реклама стоит сто лет», ПВО против пустого неба.
- **Петля:** кнопка кончается крупным планом надписи на холме — первый кадр хука.
- 7 эпох по 5–6 с; `est.py` ≈ 55 с; −14 LUFS; ударения проверены.
