# 010 — Санкт-Петербург: сценарий (v1)

Хук-спор «НЕ ПЁТР?!» — шведская крепость на Неве за 400 лет до Петра (тип «вопрос-загадка», по статистике: спор → комментарии). Структура: **«мифы и правда»** — хронология, где каждая эпоха ломает ожидание (не Пётр первый; камень налогом; музей с водкой; колонна без креплений; штурм «как в кино»). Блокада — прямо, без шуток. Финал — коты Зимнего: «Коллеги!» (Том — кот).
Оценка (`est.py`) ≈ 55 с, ударения проверены (`tools/stress.py`).
